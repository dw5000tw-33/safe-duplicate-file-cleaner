重複檔案整理工具 v1.3.1｜使用說明
================================

用途
----
找出「檔名可能不同，但副檔名、檔案大小及實際內容完全相同」的檔案。

判定方式
--------
1. 先用副檔名與檔案大小找出可能重複的檔案。
2. 再使用 SHA-256 核對實際檔案內容。
3. 只有內容完全相同才會列入同一組。

使用方式
--------
1. 務必先解壓縮整個 ZIP，不能直接在 ZIP 預覽裡執行。
2. 雙擊「start.cmd」。
3. 選擇要檢查的資料夾，例如：
   D:\資料備份\99_歷史\2026 ACER17
4. 等待檢查完成。大量檔案或大型影片會需要較長時間。
5. 完成掃描後，會開啟視覺化比較介面。
6. 每一組都會明確標示「實際內容 100% 完全相同」。
7. 點選一份真正要保留的檔案，再按「保留選取項目，其餘移除」。
8. 不想處理的群組，可按「全部保留／忽略」。
9. 桌面會出現「重複檔案檢查_日期時間」報告資料夾。

33 Works
--------
- 主畫面左上角顯示 33 Works 品牌 Icon。
- 「加入官方 LINE」會開啟 33 Works 官方 LINE 加好友頁面。
- 「支持 33 Works」會開啟綠界支持頁面。
- 支持完全自願，不影響工具的免費使用與任何功能。

報告內容
--------
- 重複檔案清單.html：適合直接查看。
- 重複檔案清單.csv：適合使用 Excel 排序、篩選。
- 處理紀錄.txt：記錄保留、忽略、移到資源回收筒或失敗的項目。
- 無法讀取的檔案.txt：只有遇到權限或檔案讀取問題時才會出現。

安全設計
--------
- 未按下確認前，工具只讀取檔案並產生報告。
- 所有移除動作都會先重新核對內容並再次確認。
- 檔案只會移到 Windows 資源回收筒，不會永久刪除。
- 每組必須由使用者親自選擇保留哪一份，不會自動刪除。

注意
----
- 相同照片若曾經縮圖、重新壓縮、裁切或修改中繼資料，內容就不再完全相同，不會被列為重複。
- 本工具目前檢查的是「完全相同檔案」，不是肉眼看起來相似的照片。
- 圖片支援縮圖預覽；其他檔案會顯示檔案類型圖示與完整路徑。
- 同一內容有三份以上時，會合併成一個群組呈現，不會兩兩重複列出。

- v1.2.1 修正 Windows PowerShell 5.1 在掃描後建立重複群組時，可能出現「引數類型不相容」的問題。
- v1.2.2 修正掃描完成後建立檔案比較表格時，DataGridView 欄位集合可能出現「AddRange／引數類型不相容」的問題。

- v1.3.1 公開版改用標準 PowerShell -File 啟動方式，不再使用 Invoke-Expression；核心掃描與安全移除流程維持不變。
