# Changelog

All notable changes to this project are documented here.

## [1.3.1] - 2026-11-18

### Changed

- Prepared the project for its public open-source release.
- Replaced the dynamic `Invoke-Expression` launcher with a standard PowerShell `-File` launch.
- Added bilingual project, privacy, security and limitation documentation.
- Added the MIT License.

### Unchanged

- Exact duplicate detection still uses file size and SHA-256.
- Every duplicate group still requires human review.
- Removed files still go to the Windows Recycle Bin.

## [1.3.0]

- Added the 33 Works brand icon.
- Added optional official LINE and support links.
- Improved action-button layout for Windows display scaling.

## [1.2.2]

- Fixed a Windows PowerShell 5.1 DataGridView `AddRange` compatibility issue.

## [1.2.1]

- Fixed a Windows PowerShell 5.1 duplicate-group argument compatibility issue.
